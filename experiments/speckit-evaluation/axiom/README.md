# Axiom Execution

This directory preserves the Axiom side of the controlled experiment.

- `prompts/`: exact phase-control prompts.
- `workflow/`: intake, clarification, specification, plan, tasks, decisions,
  validation, review, and execution evidence produced by current Axiom skills.
- `implementation/`: final sample-repository snapshot: five changed files plus
  the unchanged command reference needed to resolve links and verify scope.
- `phase-1-final.md` and `final.md`: final Codex responses from both controlled
  phases, with workspace-only links normalized to curated evidence paths.

The execution used no Spec-Kit files or commands. It did not change the Axiom
workflow after discovering deficiencies.
