# Spec-Kit Execution

This directory preserves the official Spec-Kit side of the controlled
experiment.

- `prompts/`: exact phase-control prompts.
- `official/constitution.md`: generated project constitution.
- `official/specs/`: official feature artifacts and checklists.
- `implementation/`: final sample-repository snapshot: five changed files plus
  the unchanged command reference needed to resolve links and verify scope.
- `scaffold/`: initialization and integration manifests needed to identify the
  generated Codex integration.
- `init-output.txt` and `init-timing.txt`: public initialization output and
  measured duration.
- `phase-1-final.md` and `final.md`: final Codex responses from both controlled
  phases, with workspace-only links normalized to curated evidence paths.

Spec-Kit was executed through pinned one-shot `uvx`. Nothing here represents an
Axiom dependency or adopted architecture.
