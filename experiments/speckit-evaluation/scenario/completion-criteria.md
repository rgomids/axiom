# Shared Completion Criteria

An execution is complete when its workspace contains:

1. durable intake and clarification evidence;
2. a specification with acceptance criteria and explicit non-goals;
3. a technical or artifact plan;
4. an ordered task breakdown;
5. the smallest documentation-only implementation satisfying frozen answers;
6. a review or consistency result tied to produced artifacts;
7. deterministic validation commands and outcomes;
8. documentation lifecycle treatment, including `CHANGELOG.md`;
9. explicit architecture decisions or a reason why no ADR is warranted;
10. recorded difficulties, ambiguities, and human intervention points;
11. no application code, executable validator, external dependency, provider
    mutation, or change to existing command behavior.
