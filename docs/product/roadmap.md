# Product Roadmap

Short versioned summary of capability direction for repository agents. It is
not a task tracker, changelog or delivery commitment, and nothing here
authorizes implementation.

- Product roadmap, priorities, epics and delivery status: Linear (AXM); see
  [Linear and GitHub tracking](../development/linear-github-issue-tracking.md).
- Product direction narrative: [Notion — Axiom](https://app.notion.com/p/3b4e01f22626810791b4f9d016ab5979).
- Approval and implementation status: [Specification index](../specifications/README.md).

## Current direction

[Epic #15](https://github.com/rgomids/axiom/issues/15) and
[Specification 007](../specifications/007-configurable-workflows/spec.md) define
the configurable workflow journey: explicit default/custom Project workflow
selection, stage-specific agent contracts, pinned execution, public Codex/Claude
coordination and reviewed delivery/rework. Historical Specification 002–004
Slices and Evidence supply foundations, not acceptance of this journey.

## Later capabilities requiring specification

Runtime/model ecosystem beyond the bounded Codex/Claude paths, dynamic or
distributed orchestration, additional Runtime adapters, token/cost budget
governance, richer Project setup and portable synchronization each need a
bounded Specification and explicit authority first. Evidence and human
prioritization may combine, reorder, split or defer them.
