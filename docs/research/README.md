# Research

Pesquisa registra perguntas, hipóteses, evidências e resultados de avaliação sem convertê-los automaticamente em dependências ou arquitetura.

As hipóteses iniciais estão em [../../.agents/context/research-hypotheses.md](../../.agents/context/research-hypotheses.md). RTK, Caveman, Ponytail, Graphify e Agent Skills permanecem somente referências de pesquisa; nenhum foi adotado por este bootstrap.

Uma avaliação futura deve tornar explícito se cada hipótese foi aceita, rejeitada, adiada ou substituída, com evidência verificável.
