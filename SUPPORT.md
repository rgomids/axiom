# Support

Axiom is in early development. Support is best effort, with no SLA or guaranteed response time. There is no operational support for a Lingo CLI or deployed service because neither is available yet.

- Report reproducible bugs using the [Bug form](https://github.com/rgomids/axiom/issues/new?template=bug.yml).
- Propose a user-facing outcome using the [Story form](https://github.com/rgomids/axiom/issues/new?template=story.yml); use the [Task](https://github.com/rgomids/axiom/issues/new?template=task.yml) or [Research](https://github.com/rgomids/axiom/issues/new?template=research.yml) forms for bounded technical work or open questions. See [Issue labels](CONTRIBUTING.md#issue-labels).
- For setup and validation, consult [Getting Started](docs/development/getting-started.md) and [Commands](docs/commands.md).
- Report vulnerabilities privately through [SECURITY.md](SECURITY.md).
- Report conduct concerns through the private process in the [Code of Conduct](CODE_OF_CONDUCT.md).

Do not publish sensitive questions, secrets, private data, or unsanitized logs. Use the applicable private reporting process above.

Issues do not grant priority, change the roadmap, or authorize implementation. Read [CONTRIBUTING.md](CONTRIBUTING.md) before proposing significant work.
